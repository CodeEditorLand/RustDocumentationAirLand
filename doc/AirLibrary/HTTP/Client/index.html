HTTP Client Module with DNS Override

This module provides a secured HTTP client that uses the local DNS server for all DNS resolution. This ensures that all *.land.playform.cloud queries go through the local Hickory DNS server, which resolves them to 127.x.x.x addresses as a defense-in-depth measure.
